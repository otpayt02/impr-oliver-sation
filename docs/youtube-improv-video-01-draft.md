# Video #1 Draft — The Beat Never Left

Status: local production draft. No channel, upload, title, thumbnail, description, cover performance, or publication is authorized by this document.

## Claim boundary

This video demonstrates an original performance exercise: keep an internal pulse stable while phrases create controlled rhythmic tension, then return clearly to the downbeat. It does not claim that any commercial song, artist, audience reaction, training credential, or AI analysis result is approved for public use.

## Shoot sheet

| Time | Image / sound | Spoken or on-screen point |
| --- | --- | --- |
| 0:00–0:06 | Start with the clear 4/4 performance result | “The beat never left. I just made you listen for it again.” |
| 0:06–0:18 | Hands and a simple pulse | “First I make the pulse obvious. If the listener cannot find one, the trick has nothing to return to.” |
| 0:18–0:45 | Repeat one left-hand anchor; right hand stretches a phrase | “I keep the metronome in my head. The hands can make time feel wider without moving that internal beat.” |
| 0:45–1:05 | Land cleanly on the next downbeat | “The return matters more than the confusion. That landing tells you the drift was intentional.” |
| 1:05–1:25 | Explain left-hand/rhythm role, then right-hand lead | “Piano is percussion too. In a band, the piano can give the drummer a clear interval or attack that keeps one, two, three, and four present.” |
| 1:25–1:35 | End on original resolving phrase | “Next I’ll map an improvisation: pulse, harmony, hand roles, form, and the exact moment it gets strange.” |

## Capture checklist

- Record a clean original performance at 1080p with both hands and enough keyboard visible to identify register.
- Record a separate clean stereo audio take. If MIDI is available, export it alongside the video.
- Make two takes maximum: one demonstrative, one freer. Keep the camera and audio take names paired.
- Before editing, make a timestamped improv map using `docs/improvisation-analysis-pipeline.md`.
- In the edit, use only the original performance. Keep any click private unless it helps teach the point.
