# Phase 1 Runbook v4 — Solo Improvisation Artifact

Tonight’s outcome: one locally reviewed original performance package for **The Beat Never Left**. The finish line is not a public post; it is a master performance, an improv map, a first edit, and a ready-for-approval upload packet.

## 1. Make the lead artifact — 20 minutes

- Handwrite or print one page: steady pulse, left-hand anchor, right-hand disruption, clean return to one.
- Include one simple 4/4 figure, one deliberate regrouping/displacement, and one explanation of how the piano can support the drummer.
- Photograph or scan it into `funnel/artifacts/the-beat-never-left-exercise.pdf`.

## 2. Capture — 40 minutes, two takes maximum

- Camera: both hands and enough keyboard to identify register. Audio: clean stereo capture. MIDI: export if available.
- Take A is clear and instructional. Take B is freer but must visibly return to the same internal pulse.
- Slate each take with date, original title, and intended tempo. Do not play commercial reference material in this recording.

## 3. Map the performance — 25 minutes

- Use `docs/improvisation-analysis-pipeline.md` to mark form, pulse, rhythm, harmony hypotheses, hand roles, and the moment of departure/return.
- Save the map beside the media. Mark uncertainty instead of inventing chord names or polyrhythms.

## 4. Edit — 30 minutes

- Cut the 95-second draft from `docs/youtube-improv-video-01-draft.md` at 1080p.
- Open with the clean return-to-one result. Keep captions factual and do not use claims about covers, artists, an audience, or an AI product.
- Export a local review copy. Do not upload it yet.

## 5. Approval queue — 10 minutes

- Review audio sync, visible hands, rights, and the teaching claim.
- Decide whether the video stays local, goes unlisted, or is published. Uploading or posting needs a separate explicit approval.
- Once a portfolio performance is supplied, repeat the same map with the original file preserved and a rights note.

## What is intentionally deferred

- AI improvisation analyzer product, automated stem separation, commercial-cover content, a backend offer, channel setup, payment, and public launch.
- The next safe step is a scoped product brief after one original performance has been analyzed end-to-end.
