## Operating contract (handoff §0 — outranks everything)

1. **MVP first.** Phase 0 completable tonight. No Phase 2+ scaffolding before Phase 0/1 files exist.
2. **Free tier only.** Zero-dollar is a design constraint. Paid options live ONLY in docs/upgrades-later.md.
3. **Human-in-the-loop absolutism.** Nothing auto-publishes. Every public artifact ends in queue/ awaiting Oliver's manual approval.
4. **The prime rule.** "Nothing here invents. The writer restructures Oliver; it never originates for him. If the dump didn't say it, the post doesn't say it."
5. **Token frugality.** Write files, don't narrate them. Exact paths, terse code, dense comments, batch writes.
