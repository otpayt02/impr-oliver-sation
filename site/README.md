# AP Music & Audio private release candidate

`src/main.jsx` mounts Oliver Payton's cool two-shade `DuetLanding`; its headline rotates complete curated phrases together while `your` stays visibly fixed in white, the middle phrase is blue, and the final phrase is purple. Reduced motion remains a static, readable fallback. The First Listen and checkout surfaces are rehearsal-only and must not be represented as live payment or booking.

Run `npm.cmd run build`, `npm.cmd run test`, and `npm.cmd run test:sites` from this directory before a private Sites save.
